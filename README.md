# TraceFact Web

免登入、手機可用的五大要素查核工作臺，部署於 GitHub Pages。

## 使用與範圍

品質版新增：可自行填寫「查核對象」補充脈絡；系統保留原句。自動引文從摘要內文選取，不把報告標題當成內文證據；只有標題時須先閱讀原報告，必要段落可手動補入，會標示由使用者補充且平台未自動核實。修改段落後會重設該主張的人工結論。

結果摘要區顯示有候選資料與完成人工覆核的主張數。這些是工作進度，不是真假可信度分數。

- 保持懷疑、調查來源、檢視合理性、多方交叉比對、先查證再分享。
- 瀏覽器先嘗試以關鍵詞搜尋台灣事實查核中心；原站限制瀏覽器連線時，使用網站附帶的最近 300 則報告標題及原站摘要。GitHub Actions 預定每六小時更新；實際可能延後，請看畫面的資料時間。
- 單一查核機構不等於完成多方查證；候選證據必須開原文並人工覆核。
- 本版為規則與關鍵詞輔助，沒有啟用 AI 語意模型，不會自動宣告真偽。
- 紀錄保存在 IndexedDB，不上傳 GitHub、不跨裝置同步。清除網站資料、無痕視窗關閉或瀏覽器回收儲存空間可能失去紀錄，請匯出報告備份。
- 舊站紀錄不會自動搬移；新網址擁有獨立儲存空間。

## 維護

相關性修正：不再以「不能」等語法片段或任一重疊字串推薦報告。所有即時、備援及已保存來源都先經完整詞篩選；短句（一至三詞）須符合所有檢索詞，較長句須符合至少四分之三；寧可漏掉可能相關資料，也不以少數共同詞補滿結果。資訊不足時提示補充對象，不作真假推論。這是保守的詞彙篩選，仍不是語意理解，可能漏掉同義詞或用詞不同的報告。舊檢索紀錄會提示重新查核，原紀錄不刪除。

`node scripts/build-retrieval.mjs` 將共用檢索程式更新至瀏覽器版；`node --test` 包含「沒電就不能活」及無關報告的回歸案例。

`node scripts/update-feed.mjs` 更新公開摘要；`node --test` 驗證核心規則。

`node scripts/evaluate.mjs` 執行三篇真實報告、六項人工設定相關性預期的小型評估。固定資料來自公開標題與原站摘要，保留日期、連結和使用依據。六項通過不等於整體準確率，也不測真假判定；仍需要更大且由獨立評審標註的資料集、多機構來源、語意模型和實機驗證。
網站檔案位於 `site/`。工作流程以官方 Pages Actions 發布，不需要付費 API 或網站密鑰。請在 Settings → Pages 選 GitHub Actions。

## 來源與使用依據

公開資料來自 [台灣事實查核中心](https://tfc-taiwan.org.tw/)，僅收錄標題、原站摘要、日期與連結。本專題供非營利研究，依 [原站著作權聲明](https://tfc-taiwan.org.tw/copyright-notice/) 保留出處；營利用途請另行取得授權。虛構教學資料與一般查核分開。
