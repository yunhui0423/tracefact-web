下載與還原

JSON 包含所有帳目（含回收區），可匯回本網站；CSV 供試算表分析，包含未刪除帳目。

匯入只新增不存在的紀錄；相同識別碼保留目前版本，不覆蓋現有帳目。

使用方式

  1. 拍照／上傳 JPG、PNG、WebP 帳單，或使用語音、手動輸入。
  2. 核對辨識出的日期、類型、分類與金額，再按「確認加入帳本」。辨識不會自動入帳。
  3. 總覽依所選月份自動計算收入、支出、結餘、分類與六個月趨勢。
  4. 在「我的帳目」修改記錄，統計會立即重算；誤刪可從回收區還原。

資料與辨識

帳單照片與音訊在裝置處理，不傳送辨識伺服器；首次辨識需連網下載語言與語音模型。語音使用多語言 Whisper tiny，中文、口音與背景噪音可能造成錯字；金額務必核對。沒有連接銀行、網路對帳或自動抓取銀行交易。

照片和原始音訊不加入帳本；只保存你確認的帳目欄位。語音及帳單文字可在預覽中修改。所有金額以新台幣計算，未提供匯率換算。

保存範圍

帳目只存此瀏覽器，不跨裝置同步；清除網站資料、無痕模式結束或裝置空間回收可能遺失。網站不會替你雲端備份，請定期下載 JSON。

專案與舊版資料

本網站由 TraceFact 查核平台改為口袋帳本。舊查核資料仍保留在原瀏覽器的獨立資料庫，未轉成帳目或刪除。舊版原始碼可從 GitHub 歷史版本取得。
