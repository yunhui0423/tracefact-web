WORK WITH EVIDENCE

使用指南

一次完整查核

  1. 直接貼上待查訊息，保留「自動搜尋公開查核報告」勾選，按開始查核。
  2. 平台會先搜尋公開報告並保存證據摘要。無網路時可取消勾選，使用本機快取。
  3. 逐項確認主張。若主張不完整，按「編輯主張」修正並重新搜尋。
  4. 檢查候選證據的原文、日期與對象，選擇支持、反駁、無關或待確認，儲存證據註記。
  5. 填寫覆核人、理由與結論。正反證據同時存在時，應處理矛盾或保留為證據衝突。
  6. 查看來源圖及時間排序，下載 Markdown 或 JSON 報告。

AI 如何啟用

GitHub Pages 版沒有啟用 AI 模型，提供規則提示與人工覆核。本機 AI 可拆解主張及建議證據關係；建議的引文必須通過原文逐字核對。
